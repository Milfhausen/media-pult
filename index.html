Как обновить вручную?
  1. Открой репозиторий на GitHub → вкладка Actions.
  2. Слева выбери «Сбор новостей» → справа кнопка Run workflow → зелёная Run workflow.
  3. Подожди 3–5 минут и обнови эту страницу.

Само обновляется раз в час.
