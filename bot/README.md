# 🤖 Бот «первый комментарий»

Как только в канале выходит пост, бот за секунду пишет под ним первый комментарий с кнопками **«ЧАТ»** и **«Все мои соц сети»**.

Работает бесплатно на Cloudflare Workers (до 100 000 срабатываний в день). Код — `worker.js` в этой папке.

## Шаг 1. Создать бота (2 минуты)
1. В Телеграме открой **@BotFather** → `/newbot`.
2. Имя — любое (например, «Выживаю в Лондоне»), юзернейм — латиницей, на конце `bot`.
3. BotFather пришлёт **токен** вида `1234567890:AA...`. Сохрани, никому не показывай.

## Шаг 2. Запустить бота на Cloudflare (5 минут)
1. Зарегистрируйся на https://dash.cloudflare.com/sign-up (бесплатно).
2. Слева **Workers & Pages** → **Create** → **Create Worker** (шаблон «Hello World»).
3. Имя: `vadim-bot` → **Deploy**.
4. Нажми **Edit code**, удали всё, что там есть, и вставь целиком код из `worker.js` → **Deploy**.
5. Вернись в Worker → **Settings** → **Variables and Secrets** → **Add**, добавь 4 штуки:

| Имя | Тип | Что вписать |
|---|---|---|
| `BOT_TOKEN` | Secret | токен от BotFather |
| `SECRET` | Secret | любое своё слово-пароль латиницей, например `lond0n2026` |
| `CHAT_URL` | Text | ссылка на твой чат, например `https://t.me/...` |
| `SOCIALS_URL` | Text | ссылка «все мои соцсети» (taplink / linktree / пост со ссылками) |

   По желанию: `TEXT` — свой текст сообщения, `CHAT_LABEL` / `SOCIALS_LABEL` — свои надписи на кнопках. → **Deploy**.

6. Открой в браузере (подставь свой адрес Worker'а и своё слово-пароль):
   ```
   https://vadim-bot.ТВОЙ-АДРЕС.workers.dev/setup?key=ТВОЙ_SECRET
   ```
   Должно появиться: «✅ Бот @… подключён».

## Шаг 3. Добавить бота в группу обсуждения (1 минута)
1. Открой **группу обсуждения** твоего канала (куда падают комментарии).
2. Добавь туда бота → сделай его **администратором** с правом **«Отправлять сообщения»**.

## Проверка
Опубликуй пост в канале — под ним сразу должен появиться комментарий бота с двумя кнопками.

## Если что-то не работает
- Нет комментария → проверь, что бот **админ** именно в **группе обсуждения**, а не только в канале.
- Открой адрес Worker'а без `/setup` — должно быть «Бот работает 👍».
- Поменял ссылки/текст в переменных → нажми **Deploy**, повторно `/setup` делать не нужно.
